Прикачените фајлови е потребно да се симнат. Прво се отвара фајлот proekt.py во PyCharm, и да се направи Run на истиот, доколку не ги препозае flask и flaskcore се инсталираат и повторно Run на кодот. Кога во терминалот ќе се добие IPAdress, може да преминеме на отварање на другиот фајл во WebStorm или VisualStudioCode, и потребно е да го отвориме преку некој web browser. Отварањето на фајлот ќе ја прикаже бараната страна.
